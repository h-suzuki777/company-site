# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア開発会社「株式会社スカイライン・テクノロジーズ」の1ページ・コーポレートサイトです。

建築図面(ブループリント)をモチーフにしたデザインで、以下のセクションを含みます。

- ヘッダー / ナビゲーション
- お知らせ欄
- 社員紹介
- ヒーロー(キャッチコピー)
- 実績数値
- サービス紹介
- 開発プロセス
- 導入事例
- 会社理念
- お問い合わせCTA
- 会社概要(フッター)

## 構成

- `index.html` — サイト本体。単一のHTMLファイルで、CSS・SVGイラストもすべて内包しています。
- 外部依存は Google Fonts(Zen Kaku Gothic New / Noto Sans JP / JetBrains Mono)のみで、インターネット接続が必要です。

## ブラウザで開く手順

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をダブルクリックするか、ブラウザのウィンドウにドラッグ&ドロップして開きます。
   - あるいはブラウザのアドレスバーに `index.html` のフルパスを入力してアクセスすることもできます。
3. ローカルサーバーを使いたい場合は、このディレクトリで以下のいずれかを実行してください。

   ```bash
   # Python がある場合
   python -m http.server 8000

   # Node.js がある場合
   npx serve .
   ```

   起動後、ブラウザで `http://localhost:8000` にアクセスします。
